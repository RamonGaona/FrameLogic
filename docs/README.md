# FrameLogic Documentation

## Standards

- [FrameLogic Information Standard v1](./standards/FRAMELOGIC_INFORMATION_STANDARD_V1.md) — canonical architecture for PieceDefinition, AssemblyDefinition, ProjectModel, IFC 4.3 exchange, persistent snaps, reference axes, multi-currency pricing and ISO 19650-aligned information management.

The standards documents describe target architecture. Implementation may be incremental and should preserve existing validated CAD behavior while the domain evolves.
